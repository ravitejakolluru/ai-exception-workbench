# ExceptionAI — AI Exception Resolution Workbench

Demo-ready React + Vite frontend based on the supplied App.jsx.

## Run

```powershell
cd ai-exception-workbench
npm.cmd install
npm.cmd run dev
```

Open the Vite URL shown in the terminal.

## Build

```powershell
npm.cmd run build
```

Features already included: transaction queue, search, filters, AI reasoning/confidence display, Resolve, Escalate, live counters, reset demo, responsive UI.
